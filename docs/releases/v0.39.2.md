# World of ClaudeCraft v0.39.2 更新说明

版本 0.39.2 为正式服带来了双倍荣誉周末：每个周末，5v5 夺旗战场「荆棘山谷（Thornhollow Fields）」将提供双倍荣誉点数奖励，将 PvP 玩家集中在参与度最高的排队队列中。

- **荆棘山谷双倍荣誉周末**：跨越周六和周日的每日重置窗口，荆棘山谷战场的比赛结算、击杀、助攻与首胜奖励均翻倍发放。竞技场与大乱斗保持常规速率。
- **打满全程的失败获得胜利基准荣誉**：在活动期间坚持打完整场比赛不会白费时间，打满全场的失利或平局将按照胜场基准荣誉计算。中途弃赛或逃兵不享受此福利。
- **游戏内日历与战场界面提示**：游戏内置日历展示活动具体排期，战场窗口在双倍开启期间高亮显示活动标识。
