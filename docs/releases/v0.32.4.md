**Release:** v0.32.4
**Date:** 2026-08-01
**Previous release:** v0.32.3

GLB's textures as KTX2 (the iOS world-entry memory fix), the Windows, macOS, and Linux
desktop clients froze at the "Loading world" screen: the KTX2 transcoder runs inside a
worker that inherits the desktop shell's Content Security Policy, the transcoder's
generated glue compiled code at startup, the CSP (correctly) refuses that, and every
model load then waited forever with no error shown. The web client was never affected,
