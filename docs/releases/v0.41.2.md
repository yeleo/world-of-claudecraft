# World of ClaudeCraft v0.41.2

版本 0.41.2 是针对 v0.41.1 中玩家遇到的三个问题的热修复：公会银行误将官员踢下线并提示“被另一会话接管”、熔炉军需官站位处于不可达位置、以及手机端下载了更新却未正确应用。

- **操作公会银行不再导致被踢下线**：当两名公会官员在同一个自动保存时间窗口内通过公会银行交换不同材料时，公会银行会在改动发生前予以判断，提示“公会银行仍在保存最近的更改，请稍后再试”，并立即触发该官员的保存刷新，彻底消除并发冲突断线风险。
- **熔炉军需官现已正常可达**：套装印记兑换商人此前被错误放置在城堡西墙外低处的岩架上，现在端正地站在大门下方一层的平台庭院上，从大门台阶和下方庭院均可正常步行到达。
- **原生客户端正常应用已下载的更新**：修复 iOS 与 Android 原生客户端在接收 OTA 静默更新包后出现的“版本不兼容”提示，更新包校验完成后即刻无缝生效。

**完整更新变更记录**：https://github.com/yeleo/world-of-claudecraft/releases/tag/v0.41.2
