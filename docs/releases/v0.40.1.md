# World of ClaudeCraft v0.40.1

版本 0.40.1 是将 $WOC 交易所（The $WOC Exchange）正式推进到生产运营环境的关键补丁，同时加固了公会离线加入机制，并修复了两个导致大世界循环卡顿的服务器性能缺陷。

- **运营后台结算裁决**：引入专门的结算状态机与裁决接口，区分交易争议与异常漏单。
- **更换提现钱包需二次验证**：更换绑定地址或解除绑定强制要求当前钱包的联合签名，或账户密码加二次验证（2FA），并在任何变动时发送告警邮件。
- **公会申请持久化与离线批准**：公会申请现在会在角色下线后持久保存；官员批准离线申请人的请求后，该玩家在下次上线时将直接成为公会正式成员。
- **性能优化：消除全服邮件大对象扫描阻塞**：将全服邮件与市场数据聚合计算全部下沉至 Postgres 数据库内部执行，大世界循环完全恢复丝滑顺畅。
