# World of ClaudeCraft v0.40.1 更新说明

**发布日期：** 2026-08-27 | **上一版本：** v0.40.0

版本 0.40.1 是将 $WOC 交易所（The $WOC Exchange）从预备功能正式推进到生产运营环境的关键补丁，同时加固了公会离线加入机制，并修复了两个导致大世界循环卡顿的服务器性能缺陷。

## $WOC 交易所

- **运营后台结算裁决**：引入专门的结算状态机与裁决接口，区分交易争议与异常漏单，在交易暂停期间依然保持安全审计能力。
- **更换提现钱包需二次验证**：由于市场收益将发放至关联的 Solana 钱包，更换绑定地址或解除绑定现在强制要求当前钱包的联合签名，或账户密码加二次验证（2FA），并在任何变动时发送告警邮件。
- **交易所直观展示钱包状态**：交易所面板顶部新增专属钱包状态卡片，支持一键连接、验证、重连与管理。
- **市场条款与风险披露正式生效**：在客户端法律与条款页面完整上线了最新的服务协议与合规披露。

## 公会系统

- **公会申请持久化与离线批准**：公会申请（Pledges）现在会在角色下线后持久保存；官员批准离线申请人的请求后，该玩家在下次上线时将直接成为公会正式成员，彻底解决了离线无法入会的痛点。
- **性能优化：消除全服邮件大对象扫描阻塞**：管理后台每 60 秒刷新一次账户财富总额，此前会将全服所有邮件与市场数据打包进 Node 内存计算，导致世界循环每分钟出现约 400 毫秒卡顿。现已将聚合计算全部下沉至 Postgres 数据库内部执行，大世界循环完全恢复丝滑顺畅。
