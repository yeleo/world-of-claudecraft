# World of ClaudeCraft（克劳德争霸） v0.24.2 Release Notes
**Release:** v0.24.2
**Previous release:** v0.24.1
v0.24.2 is a gameplay reliability patch. It closes a set of heroic dungeon reward and loot-roll races, makes the loot-roll prompt reliable on short mobile screens, and clears one stale saved layout value left over from the v0.24.1 revert.
## What changed
### Heroic rewards and mobile loot ([#1806](https://github.com/levy-street/world-of-claudecraft/pull/1806))
- Heroic final-boss kills no longer persist a lockout while losing the corresponding Heroic Mark, corpse loot, or Need/Greed award. Marks are now awarded directly at final-boss death and use the same realm-local reset boundary as the heroic lockout, removing the former UTC-day mismatch.
- A claim-bound participation snapshot covers both living and released players, so releasing, instance-slot reuse, party changes, and logout can no longer produce a lockout-without-reward result.
- Reward eligibility is frozen before the disconnect save yields: pending and master-loot items are conserved, corpse rights and party loot strategy are preserved when the original tapper leaves, and stale post-snapshot commands are rejected.
- Server-authoritative roll prompts reconcile after a dropped submit. A just-answered roll no longer flashes back with live buttons for a server round trip, while a genuinely dropped submit still restores its buttons after a short grace.
