# World of ClaudeCraft（克劳德争霸） v0.33.1 Release Notes
**Release:** v0.33.1
**Date:** 2026-08-02
**Previous release:** v0.32.4
Version 0.33.1 is the first published release on the 0.33 line. The 0.33.0 release merged to
main on 2026-08-01 but was never tagged, so these notes cover the whole line: the 0.33.0
feature release (the graphics and performance overhaul, the per-ability spell VFX and SFX
stack, and Epic Games as a distribution channel) plus the 0.33.1 patch, which recovers the
frame pacing the overhaul left on the table, lets the Wildheart Basin boss punish reach the
whole basin, and repairs the bloom constructor against the current Three.js shader shape.
