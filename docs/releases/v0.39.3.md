# World of ClaudeCraft v0.39.3

版本 0.39.3 将双倍荣誉周末（Double Honor Weekend）的开启时间提前了 12 个小时，以使活动能完整覆盖全球所有时区玩家的整个周末。

- **双倍荣誉时间调整**：服务器时间每周五下午 3 点持续至周一凌晨 3 点。荆棘山谷战场（Thornhollow Fields）的全部荣誉奖励（比赛结果、击杀、助攻及首胜加成）全额享受双倍收益。
- **失败队伍保底收益**：在活动开放期间，打满全程的失利或平局比赛依然按胜利基础分发放荣誉。
