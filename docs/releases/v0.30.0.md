# World of ClaudeCraft（克劳德争霸） v0.30.0 Release Notes
**Release:** v0.30.0
**Date:** 2026-07-26
**Previous release:** v0.29.1
Version 0.30.0 turns enchanting into a system you can actually live with: enchants apply to the
gear you are wearing and can be replaced later, and the enchanting screens now explain what every
choice does. Alongside it, the release adds a second ranked arena map, rebalances critical strike
and haste onto the classic stat ladder, retunes normal Gravewyrm Sanctum for freshly capped
groups, replaces the procedural item and HUD icons with painted art, rebuilds 东溪谷（Eastbrook） Vale's town
center with hand-crafted models, gives professions and consumables real recorded sound, and fixes
