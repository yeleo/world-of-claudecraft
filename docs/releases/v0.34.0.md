# World of ClaudeCraft（克劳德争霸） v0.34.0 Release Notes
**Release:** v0.34.0
**Date:** 2026-08-05
**Previous release:** v0.33.1
Version 0.34.0 is a big economy and world release: the guild bank arrives, mount reins
become tradable goods alongside a reworked Drakelands and its new Dragonkin brood,
professions gain the tool-effect charm economy and a real fishing-to-cooking loop, and the
game grows an official Discord presence. 芬桥镇（Fenbridge） is rebuilt from the ground up, crowds
render lighter, rift bosses fight fair, and the whole release ships fully localized across
all 21 locales (971 commits since v0.33.1).
