# World of ClaudeCraft（克劳德争霸） - v0.24.0 Release Notes
**Release:** v0.24.0
**Date:** 2026-07-12
**Previous release:** v0.23.0
v0.24.0 is a polish and infrastructure release, with **376 commits** since v0.23.0 (this range also folds in the unpublished v0.23.1 hotfix line). It ships a production-grade interface overhaul (a shared window frame across nineteen windows and a completely rebuilt Esc settings menu with the game's first controller menu navigation), spell queueing in the combat core, a heroic loot upgrade wave with soulbound Heroic Marks and a watertight whole-party daily lockout, party and raid ready checks, a major crowd-rendering performance win (one draw per remote player instead of nine), background terrain streaming for a much faster load, native Discord and Apple sign-in in the mobile apps, self-service password reset backed by a real AWS SES email transport, an in-game jail for moderators, unified moderation history and Daily Rewards bans in the admin dashboard, a modernized default keyboard layout, and a full translation pass taking every one of the 21 non-English locales to zero pending strings.
## Highlights
- **The interface overhaul:** nineteen game windows move onto one shared window grammar (titlebar, tabs, sticky footer, rarity-bordered item cells) with dragging, resizing, viewport clamping, and cascading; the Esc settings menu is rebuilt from scratch with a category rail, global settings search, per-category resets, a real rebinding UX, and full controller navigation; vendors become tabbed Browse/Sell/Buyback shops; the talents window becomes a classic tiered-choices picker (#1736).
- **Spell queueing:** pressing your next ability during the last 0.4 seconds of a cast now queues it to fire the instant the cast completes, re-validated at fire time, identical offline and online (#1648).
- **Heroic loot, upgraded and locked down:** heroic dungeon drops come out as upgraded item-level 28 epics and 25 rares with a gold [HEROIC] tooltip tag, Heroic Marks become soulbound, the final boss pays every earner's marks through one shared loot, and the daily lockout now binds the entire party with a boss-alive door gate that ends the re-run abuse (#1705, #1767).
- **Crowds at full frame rate:** every character rig now renders in one skinned draw instead of about nine, taking a 90-player crowd from 45.4 to 61.3 fps (+35%), with crowd-adaptive animation LOD that never degrades you, your target, or anything mid-cast (#1726).
