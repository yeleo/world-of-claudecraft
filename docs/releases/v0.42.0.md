# World of ClaudeCraft v0.42.0 更新说明

**发布日期：** 2026-09-09 | **上一版本：** v0.41.4

版本 0.42.0 是游戏历史上规模最庞大的一次内容更新：自 v0.41.4 以来共包含 **2,512 次提交** 与约 **120 个合并请求（PR）**。本次更新带来了全新的终局制造机制、耕种业专业技能，并对东溪谷（Eastbrook）前期体验进行了全面重构。

- **大师锻造（Masterwrought）终局制造**：工匠们现在可以锻造出拥有独特属性词条的卓越终局神兵与防具。
- **全新专业：耕种业（Farming）**：玩家可以在自己的领地开垦农田、种植魔法作物并收获稀有炼金与制造素材。
- **东溪谷新手引导重制**：为新玩家量身定制了更沉浸的前期教程，引入了摆渡人奥多（Ferryman Odo）的全程引导语音与营地指引。
- **全职业平衡性重塑**：对战士、潜行者、法师、圣骑士等全部首发职业的战斗循环、天赋树和技能手感进行了全方位打磨。
- **三维世界引擎与视觉升级**：全面优化了高动态光照（HDR）、植被风动渲染以及水面反射效果。
