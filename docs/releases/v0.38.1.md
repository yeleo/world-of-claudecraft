# World of ClaudeCraft v0.38.1 更新说明

版本 0.38.1 针对 v0.38.0 中引擎升级遗留的两个问题进行热修复：转身时追随镜头瞄准位置滞后一帧导致的晃动，以及 Dockerfile 构建上下文缺失的问题。

- **镜头朝向对齐**：修复摄像机矩阵自动更新未及时触发导致角色转身时偏离屏幕中央的视角滞后问题。
- **Docker 镜像构建修复**：补齐构建上下文依赖，确保服务器容器镜像顺畅打包。
