# World of ClaudeCraft v0.40.0

World of ClaudeCraft 迎来重磅社交里程碑：公会系统（Guilds）全面上线！

- **公会创建与徽章定制**：玩家可在芬桥镇公会办事处组建自己的公会，挑选公会旗帜、战袍底色与独一无二的纹章图样。
- **公会等级与专有特权**：与公会成员共同通关地下城、完成每日任务可提升公会声望与等级，解锁公会全员骑乘移速加成、修理费用打折与公会金库扩容。
- **公会金库（Guild Bank）**：多标签页共享仓库，会长可细致划分不同公会阶级的存取权限与每日金币支取额度。
- **专属公会频道**：全服跨区域公会聊天频道，无论身处世界任何角落皆可实时交流。
