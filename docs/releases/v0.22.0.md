# World of ClaudeCraft（克劳德争霸） - v0.22.0 Release Notes
**Release:** v0.22.0
**Date:** 2026-07-06
**Previous release:** v0.21.0
v0.22.0 is a platform, infrastructure, and polish release with **526 commits** since v0.21.0. The headline is the server REST re-architecture: the main, admin, OAuth, internal, wallet, character, Discord, maps, reports, daily rewards, and related surfaces now run through a shared route registry, middleware pipeline, typed schema layer, structured logging, request IDs, stable API error codes, RED metrics, security headers, ownership gates, and parity tests.
This release also improves terrain and water rendering, hardens reconnect behavior, adds daily delve reward points, improves character select and mailbox UX, prepares the macOS desktop launcher download for the 0.22.0 deploy, and deliberately removes the unstable mobile HUD/control work from the release branch so it can continue in its own PR.
## Highlights
- **REST API re-architecture:** a new RouteDef registry, path-pattern router, onion middleware stack, request context, CORS, body/raw-body handling, error serializers, security headers, ownership loaders, admin guards, internal-secret gates, and exhaustive parity/characterization tests now cover the server API surface (#1491).
- **Observability and safety:** structured access logs, request IDs, secret redaction, RED Prometheus metrics, drain-aware health checks, rate-limit metrics, auth-failure/BOLA attack-signal counters, and throttled fail-open database limiter logs are in place (#1491).
- **Stable localized API errors:** migrated server surfaces now emit stable machine-readable error codes with localized client prose fallback across the supported locales (#1491).
