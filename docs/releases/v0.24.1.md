# World of ClaudeCraft（克劳德争霸） v0.24.1 Release Notes
**Release:** v0.24.1
**Previous release:** v0.24.0
v0.24.1 is a desktop stability hotfix. It reverts the interface overhaul from [#1736](https://github.com/levy-street/world-of-claudecraft/pull/1736) after the overhaul significantly regressed the desktop experience.
## What changed
- Reverts the complete net change from #1736 by rolling back merge commit `feac4d7a1db830851d8cd357572285ed65007005` against its first-parent baseline. This removes all 195 commits from the overhaul as one coherent rollback.
- Restores the pre-overhaul desktop interface behavior, including the prior window, settings, vendor, talent, and related HUD presentation.
- Preserves later work that landed after #1736 where histories overlapped, including the pooled nameplate decluttering and rendering improvements.
- Removes the reverted interface's localization keys and downstream test artifacts.
