# World of ClaudeCraft（克劳德争霸） v0.37.1 Release Notes
**Release:** v0.37.1
**Date:** 2026-08-13
**Previous release:** v0.37.0
Version 0.37.1 is a hotfix for the battleground queue. Since the v0.36.0 deploy, queue
pops fired their cue and chat line but never showed the Accept/Decline prompt for some
players; silence counted as a decline, so pops churned and no battleground match could
seat. The prompt is restored, and the dungeon finder's "group found" prompt — which
carried the identical flaw with a wider window — gets the same fix.
