# World of ClaudeCraft（克劳德争霸） v0.29.0 Release Notes
**Release:** v0.29.0
**Date:** 2026-07-23
**Previous release:** v0.28.0
Version 0.29.0 finalizes Professions 2.0 as a complete, balanced crafting economy. Every
character's profession skills are reset to 0 one time with this release so progression starts on
the finished mastery curve. The release also retunes dungeon and raid difficulty, fills
long-standing class loot gaps, refreshes a large part of the interface, streams a remastered
soundtrack, adds an AAA camera feel pass, and lands substantial server reliability and security
work.
